# Лабораторная работа 1

## Задание

**Вариант 40.** Сверстать флаг Бангладеша. Красный круг в центре необходимо
сделать с помощью `position: absolute`, разместив его точно по центру (чтобы он
оставался по центру даже при изменении размеров флага).

## Реализация

Проект состоит из семантически валидного HTML (`index.html`) и таблицы стилей
(`styles.css`).

- Главный контейнер `.flag-bangladesh` использует `position: relative`, выступая
  в роли точки отсчета для дочернего элемента.
- Элемент `.flag-circle` центрируется с помощью классического CSS-паттерна:
  - `position: absolute;`
  - `top: 50%; left: 50%;`
  - `transform: translate(-50%, -50%);`
- Для предотвращения появления горизонтальной прокрутки у флага задано свойство
  `max-width: 100%`.
- Встроенные (inline) стили не используются, все требования DOM/CSS-контракта
  соблюдены.

## Запуск

Откройте `index.html` в браузере.
