# Лабораторная работа 3

## Задание

**Вариант 40.** Функция `moveZerosToEnd`. Реализуйте функцию
`moveZerosToEnd(arr)`, которая перемещает все строгие числовые нули в конец
массива. Порядок остальных (ненулевых) элементов должен быть сохранен.

## Реализация

Решение реализовано на TypeScript в файле `solution.ts`. Функция экспортируется
под именем `moveZerosToEnd`.

**Алгоритм:**

1. Создаются два пустых массива: один для хранения ненулевых элементов, другой
   для нулей.
2. Происходит итерация по элементам переданного массива.
3. Каждый элемент проверяется с помощью строгого равенства (`item === 0`). Это
   гарантирует, что переноситься будут только числа `0` (и `-0`), тогда как
   другие falsy-значения (например, `false`, `null`, `undefined`, `""` или
   строковый `'0'`) останутся на своих местах.
4. В конце возвращается новый массив, состоящий из элементов первого списка, к
   которому присоединены элементы второго.

**Граничные случаи:**

- Массив с элементами разных типов (строки, объекты, логические значения)
  обрабатывается корректно — переносятся только числа `0`.
- Пустой массив возвращает пустой массив.
- Массив, состоящий только из нулей или вообще не содержащий нулей,
  обрабатывается без ошибок.
- Исходный массив не мутирует, так как формируется и возвращается совершенно
  новый массив.

## Запуск

Импортируйте именованный export из `solution.ts` как ES module:

```typescript
import {moveZerosToEnd} from './solution.ts';

const original = [false, 1, 0, 1, 2, 0, 1, 3, 'a'];
const result = moveZerosToEnd(original);

console.log(result);
// Вывод: [false, 1, 1, 2, 1, 3, "a", 0, 0]
```
