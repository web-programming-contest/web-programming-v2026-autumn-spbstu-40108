# Лабораторная работа 2

## Задание

**Вариант 40.** Функция `timeAgo`. Необходимо реализовать функцию, которая
принимает дату (объект `Date` в прошедшем времени) и возвращает строку с
описанием того, сколько времени прошло с этой даты. Функция должна выбирать
целые минуты, часы или дни и использовать корректную русскую форму (например, "5
минут назад", "2 часа назад", "3 дня назад").

## Реализация

Решение реализовано на TypeScript и экспортируется как ES-модуль (именованный
экспорт `timeAgo`).

**Алгоритм работы:**

1. Функция вычисляет разницу в миллисекундах между текущим временем
   (`new Date()`) и переданной датой.
2. Полученная разница конвертируется в целые минуты, часы и дни с помощью
   `Math.floor`.
3. Условия проверяют наибольшую релевантную единицу измерения:

- `< 60 минут` → выводятся минуты;
- `< 24 часов` → выводятся часы;
- `≥ 24 часов` → выводятся дни.

4. Вспомогательная функция `getPluralForm` вычисляет остаток от деления для
   подстановки правильного окончания слов в зависимости от числительного,
   соблюдая правила русского языка (включая исключения для чисел 11–19).

**Граничные случаи:**

- Если разница составляет меньше 1 минуты, функция возвращает `"0 минут назад"`.
- Передача даты, которая находится "в будущем", не сломает приложение — разница
  ограничивается нулем, и возвращается `"0 минут назад"`.
- Функция является чистой относительно аргументов: переданный объект `Date` не
  мутируется.

## Запуск

Импортируйте именованный export из `solution.ts` как ES module:

```typescript
import {timeAgo} from './solution.ts';

const date = new Date(Date.now() - 5 * 60 * 1000); // 5 минут назад
console.log(timeAgo(date)); // Выведет: "5 минут назад"
```
