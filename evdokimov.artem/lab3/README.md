# Лабораторная работа 3

## Задание

Вариант 10. Реализовать функцию `findMedian(arr)`, которая вычисляет медиану
непустого числового массива.

## Реализация

Функция создаёт копию массива и сортирует её по возрастанию. При нечётном
количестве элементов возвращается центральное число, а при чётном — среднее
арифметическое двух центральных чисел. Исходный массив не изменяется.

## Запуск

Из корня репозитория выполните:

```bash
node --input-type=module -e "import {findMedian} from './evdokimov.artem/lab3/solution.js'; console.log(findMedian([3, 1, 2]));"
```

Результат: `2`.
