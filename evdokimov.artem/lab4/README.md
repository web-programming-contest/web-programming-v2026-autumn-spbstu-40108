# Лабораторная работа 4

## Задание

Вариант 10: создать модель блог-поста с тегами и комментариями, функции для
работы с коллекцией постов и интерфейс для управления ими.

## Реализация

Класс `BlogPost` и пять функций коллекции находятся в `model.js`. Интерфейс
`main.js` позволяет добавлять и удалять посты и теги, добавлять комментарии,
отображает количество постов и комментариев. Изменения выполняются асинхронно
через `Promise` и `setTimeout`, сохраняются в `localStorage` и восстанавливаются
после перезагрузки страницы. Теги и комментарии видны в каждой карточке. Там же
можно добавлять и удалять теги и добавлять комментарии. Номер нового поста можно
указать вручную; если поле оставить пустым, он присваивается автоматически. Теги
можно указать через запятую при создании и изменить после публикации. Текст
поста виден сразу в карточке. Его можно оставить пустым.

## Запуск

Из корня репозитория запустите локальный сервер:

```bash
python3 -m http.server 8000
```

Откройте в браузере `http://localhost:8000/evdokimov.artem/lab4/`.
