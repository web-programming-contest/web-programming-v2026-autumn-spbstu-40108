# Лабораторная работа 2

## Задание

Вариант 10. Написать функцию `findMissingNumber(arr)`, которая находит одно
пропущенное число в массиве целых чисел от 1 до N.

## Реализация

Функция определяет N по длине массива, вычисляет сумму чисел от 1 до N и
вычитает из неё сумму элементов массива. Полученная разница — пропущенное число.
Исходный массив не изменяется.

## Запуск

Из корня репозитория выполните:

```bash
node --input-type=module -e "import { findMissingNumber } from './evdokimov.artem/lab2/solution.js'; console.log(findMissingNumber([1, 2, 4, 5]));"
```

Результат: `3`.
