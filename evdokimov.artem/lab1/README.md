# Лабораторная работа 1

## Задание

Вариант 10: создать двухколоночную форму регистрации с текстовыми полями,
выбором пола и несколькими вариантами языков.

## Реализация

Страница содержит форму с полями имени и фамилии, группой переключателей и
группой флажков. Подписи и поля расположены в двух колонках. Для разметки
использован HTML, а строки формы сгруппированы с помощью `div` и расположены в
две колонки с помощью CSS Grid. Оформление выполнено в тёмном стиле с белым
текстом и синим акцентом.

## Запуск

Откройте `index.html` в браузере. Форма демонстрирует разметку и не подключена к
серверу.
