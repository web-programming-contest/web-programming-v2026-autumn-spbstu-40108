# Лабораторная работа 3

## Задание

Вариант 2. Реализовать функцию rotateArray, которая сдвигает массив вправо на
указанное число элементов. Функция должна экспортироваться как именованный
ESM-export и возвращать новый массив, не изменяя исходный. Пример работы:
rotateArray от массива [1, 2, 3, 4, 5] с шагом 2 возвращает [4, 5, 1, 2, 3].

## Реализация

Функция нормализует число шагов через остаток от деления на длину массива, что
позволяет корректно обрабатывать шаги, превышающие длину, отрицательные значения
и нулевые шаги. Затем массив разбивается на две части: последние шаги элементов
и все остальные. Обе части объединяются через concat, образуя новый массив.
Исходный массив не мутируется.

Граничные случаи: пустой массив возвращает пустой массив, нулевые шаги
возвращают копию, отрицательные значения приводятся к положительным.

## Запуск

Решение находится в файле solution.js и является ES-модулем. Функция доступна
как именованный экспорт rotateArray. Для запуска импортируйте её в тестовом
файле и вызовите с нужными аргументами.
