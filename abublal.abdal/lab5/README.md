# Лабораторная работа 5

## Задание

Вариант 2. Реализовать пагинацию книг в книжном интернет-магазине.

- Список книг содержит обложку, название, рейтинг, описание и цену.
- 9 книг, по 3 элемента в строке.
- Под списком находится пагинация с кнопками «назад», «вперёд» и номерами
  страниц.
- Учитывается, что страниц может быть до 20.

## Реализация

Приложение написано на React + Vite. Компонент `App` хранит текущую страницу в
состоянии (`useState`). Компонент `BookCard` отображает одну книгу, `Pagination`
— кнопки и номера страниц. Данные о книгах лежат в `src/data.js`. CSS использует
Grid для сетки 3 в ряд и Flexbox для пагинации.

Публичные атрибуты `data-testid`:

- `app` — корневой элемент;
- `book-list` — контейнер списка книг;
- `book-card` — карточка книги;
- `pagination` — контейнер пагинации;
- `pagination-prev`, `pagination-next`, `pagination-page` — кнопки.

## Запуск

```bash
cd abublal.abdal/lab5
npm install
npm run dev
```
