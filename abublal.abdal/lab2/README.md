# Лабораторная работа 2

## Задание

Вариант 2. Реализовать функцию `toRoman(num)`, преобразующую целое число от 1 до
3999 в его римскую запись. Функция должна экспортироваться как именованный
ESM-export `toRoman` и возвращать строку, а не выводить результат в консоль.

## Реализация

Функция `toRoman` использует таблицу соответствий между арабскими и римскими
значениями, упорядоченную по убыванию. На каждом шаге из входного числа
вычитается наибольшее возможное значение из таблицы, а соответствующий символ
добавляется к результату. Такой подход автоматически обрабатывает вычитательные
формы (IV, IX, XL, XC, CD, CM) без отдельных условий.

Граничные случаи:

- допустимый диапазон: 1 ≤ `num` ≤ 3999;
- при выходе за диапазон или при нецелом числе выбрасывается `RangeError`;
- для значения 3999 возвращается `MMMCMXCIX`.

## Запуск

Решение находится в `solution.js` и является ES-модулем. Функция доступна как
именованный export:

```js
import {toRoman} from './solution.js';

console.log(toRoman(1994)); // MCMXCIV
```
