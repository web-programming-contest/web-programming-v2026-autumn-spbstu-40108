# Лабораторная работа 3

## Задание

Вариант 9. Реализовать именованно экспортируемую функцию
`findPairsWithSum(arr, sum)`, возвращающую уникальные неупорядоченные пары чисел
с заданной суммой.

## Реализация

`solution.js` перебирает пары разных индексов, нормализует порядок чисел и
исключает повторяющиеся пары. Исходный массив не изменяется.

## Запуск

Импортируйте `findPairsWithSum` из `solution.js` как ES-модуль и передайте
массив чисел и искомую сумму.
