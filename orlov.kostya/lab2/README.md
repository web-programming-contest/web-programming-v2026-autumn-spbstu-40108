# Лабораторная работа 2

## Задание

Вариант 9. Реализовать именованно экспортируемую функцию `isBalanced(str)`,
которая проверяет баланс скобок `()[]{}`. Остальные символы игнорируются, пустая
строка сбалансирована.

## Реализация

`solution.js` проверяет строку стеком: открывающие скобки помещаются в стек, а
закрывающие должны соответствовать последней открывающей.

## Запуск

Импортируйте `isBalanced` из `solution.js` как ES-модуль и вызовите функцию со
строкой.
