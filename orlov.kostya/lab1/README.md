# Лабораторная работа 1

## Задание

Вариант 9. Создать каталог товаров, сгруппированных по категориям. Категории и
товары представлены вложенными списками. У каждого товара есть название, краткое
описание и цена.

## Реализация

Каталог состоит из трех категорий с двумя товарами в каждой. Названия выделены
полужирным, цены выделены курсивом. Страница адаптируется к узким экранам и
использует только локальные ресурсы.

## Запуск

Откройте `index.html` в браузере. Сторонние зависимости не требуются.
