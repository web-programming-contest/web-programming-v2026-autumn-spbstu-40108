# Лабораторная работа 3

## Задание

Вариант 18. Реализуйте функцию findLongestIncreasingSubsequence(arr), которая
находит длину наибольшей возрастающей подпоследовательности.

## Реализация

Экспортируется именованная функция `findLongestIncreasingSubsequence(arr)`.
Используется динамическое программирование: в массиве `lengths` для каждого
элемента хранится длина самой длинной возрастающей подпоследовательности,
которая на нём заканчивается. Для каждого `arr[i]` в `lengths` сначала
добавляется 1, затем перебираются элементы левее него, и если `arr[j] < arr[i]`,
то `lengths[i]` заменяется на `lengths[j] + 1`, когда это больше. Ответ равен
максимуму в `lengths`, для пустого массива возвращается 0. Сложность O(n²).

## Запуск

Импортируется именованная функция из `solution.js`.
