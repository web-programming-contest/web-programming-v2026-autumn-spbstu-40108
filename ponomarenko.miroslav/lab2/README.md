# Лабораторная работа 2

## Задание

Вариант 18. Написать функцию, которая проверяет, является ли строка панграммой
(содержит ли строка все буквы алфавита).

## Реализация

Экспортируется именованная функция `isPangram(str)`. Строка приводится к нижнему
регистру, затем в цикле `for...of` для каждой буквы от `a` до `z` через
`includes` проверяется, есть ли она в строке. Если какой-то буквы нет, функция
сразу возвращает `false`, иначе после цикла возвращает `true`. Для пустой строки
возвращается `false`.

## Запуск

Импортируется именованная функция из `solution.js`.
