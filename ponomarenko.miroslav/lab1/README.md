# Лабораторная работа 1

## Задание

Вариант 18.

Создать карточку товара с изображением, названием и ценой. При наведении курсора
на карточку должно происходить изменение её внешнего вида:

- Фон: Цвет фона карточки изменяется на светло-голубой (#e0f7fa);
- Тень: К карточке добавляется размытая тень с небольшим смещением (смещение
  тени по горизонтали и вертикали 5px, радиус размытия тени 10px, цвет тени
  черный, прозрачность 20%);
- Масштабирование: Размер изображения увеличивается на 10% от исходного размера.
- Все изменения должны происходить одновременно.

## Реализация

Страница создана на HTML и CSS. Файлы проекта:

- index.html: разметка карточки (картинка, название и цена);
- styles.css: размеры карточки и эффекты при наведении;
- assets/headphones.png: изображение товара.

Карточка сделана блоком div с классом card внутри main. При наведении на
карточку (.card:hover) фон меняется на #e0f7fa и появляется тень box-shadow: 5px
5px 10px чёрного цвета с прозрачностью 0.2. Картинка увеличивается на 10% с
помощью transform: scale(1.1).

Все изменения происходят одновременно, потому что срабатывают от наведения на
одну карточку, а у карточки и картинки одинаковый transition: all 0.3s.

## Запуск

Откройте `index.html` в браузере.
