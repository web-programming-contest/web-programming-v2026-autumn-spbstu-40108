# Лабораторная работа 2

## Задание

Вариант 21. Написать функцию, которая возвращает все простые числа до заданного
числа включительно.

## Реализация

Функция `generatePrimes(n)` перебирает числа от 2 до `n`. Для каждого числа
проверяет возможные делители от 2 до квадратного корня включительно. Если число
не делится ни на один из них, функция добавляет его в массив. При `n < 2`
возвращает пустой массив.

## Запуск

Из папки `pylenkov.elisey/lab2/` выполнить:

```bash
node --input-type=module -e "import { generatePrimes } from './solution.js'; console.log(generatePrimes(10));"
```

Результат: `[2, 3, 5, 7]`.
