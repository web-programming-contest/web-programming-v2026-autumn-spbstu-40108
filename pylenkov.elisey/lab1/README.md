# Лабораторная работа 1

## Задание

Вариант 21. Создать горизонтальное меню навигации, которое при ширине экрана
менее 768 пикселей становится вертикальным.

## Реализация

Меню находится в элементе nav в файле index.html. В файле styles.css для списка
ссылок используется Flexbox. По умолчанию пункты расположены в строку.
Медиазапрос при ширине окна до 767 пикселей включительно меняет направление на
column.

## Запуск

Открыть index.html в браузере. Уменьшить ширину окна до 767 пикселей и
проверить, что пункты меню расположились вертикально.
