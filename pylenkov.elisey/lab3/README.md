# Лабораторная работа 3

## Задание

Вариант 21. Найти максимальную сумму непрерывного подмассива длины `n`. Длина
подмассива удовлетворяет условию `1 <= n <= arr.length`.

## Реализация

Функция `findMaxSubarraySum(arr, n)` вычисляет сумму первых `n` элементов и
сохраняет её как начальный максимум. Затем сдвигает окно на один элемент вправо:
вычитает число, которое вышло из окна, и прибавляет число, которое вошло. После
каждого сдвига функция обновляет максимум и в конце возвращает его.

Начальный максимум равен сумме первого окна, поэтому функция корректно работает
и с отрицательными числами.

## Запуск

Из папки `pylenkov.elisey/lab3/` выполнить команду:

```bash
node --input-type=module -e "import { findMaxSubarraySum } from './solution.js'; console.log(findMaxSubarraySum([2, -1, 5, 1, 3], 3));"
```

Результат — `9`. Максимальную сумму дают три соседних элемента `[5, 1, 3]`.
