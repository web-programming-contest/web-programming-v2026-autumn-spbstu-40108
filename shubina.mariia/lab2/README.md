# Лабораторная работа 2

## Задание

Реализовать функцию `countVowels(str)`, которая возвращает количество гласных
букв (a, e, i, o, u) в строке без учёта регистра.

## Реализация

Решение находится в `solution.js` и является ES module: функция экспортируется
именованным экспортом `export function countVowels`. Строка приводится к нижнему
регистру методом `toLowerCase()`, затем цикл `for...of` проходит по символам, и
каждый символ, входящий в строку `'aeiou'`, увеличивает счётчик. Функция
возвращает число, а не выводит его в консоль. Для пустой строки и для строки без
гласных результат равен 0, для значения, не являющегося строкой, также
возвращается 0.

## Запуск

Функция подключается так: `import { countVowels } from './solution.js';`.
Пример: `countVowels('Hello World')` возвращает `3`. Для ручной проверки можно
открыть консоль браузера (F12), вставить код функции и вызвать её с любой
строкой.
