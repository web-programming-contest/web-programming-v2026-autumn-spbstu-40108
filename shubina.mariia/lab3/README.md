# Лабораторная работа 3

## Задание

Реализовать функцию `shuffleArray(arr)`, которая перемешивает элементы массива в
случайном порядке.

## Реализация

Решение находится в `solution.js` и является ES module: функция экспортируется
именованным экспортом `export function shuffleArray`. Используется алгоритм
Фишера-Йетса: массив обходится с конца, на каждом шаге выбирается случайный
индекс от 0 до текущего, и элементы меняются местами. Функция работает с копией
массива и возвращает новый массив, поэтому входной массив не изменяется. Пустой
массив и массив из одного элемента возвращаются без ошибок.

## Запуск

Функция подключается так: `import { shuffleArray } from './solution.js';`.
Пример: `shuffleArray([1, 2, 3, 4, 5])` вернёт те же числа в случайном порядке.
Для ручной проверки можно открыть консоль браузера (F12), вставить код функции и
вызвать её с любым массивом.
