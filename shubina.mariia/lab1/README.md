# Лабораторная работа 1

## Задание

Создать три карточки товара. Каждая карточка - блок `div`, внутри которого
изображение размером 200px на 150px, заголовок (Arial, 18px, жирный) и описание
(Arial, 14px). Карточки расположены в одну строку с отступом 20px между ними.
Для всех элементов задан `padding: 10px`.

## Реализация

Страница состоит из `index.html` и `styles.css`, инлайн-стилей нет. Карточки
лежат в контейнере `main.cards`, который выстраивает их в строку через
`display: flex` с `gap: 20px`. Каждая карточка - `div.card` с элементами `img`,
`h3` и `p`. Стили элементов заданы в `styles.css`. Для узких экранов включён
`flex-wrap: wrap`, чтобы не появлялась горизонтальная прокрутка. Товары: носки,
тушь, огурцы, изображения `card_1.png`, `card_2.png`, `card_3.png` лежат в папке
`assets`.

## Запуск

Откройте файл `index.html` в браузере двойным щелчком. Файл `styles.css` должен
лежать рядом с `index.html`, а изображения `card_1.png`, `card_2.png`,
`card_3.png` в папке `assets`.
