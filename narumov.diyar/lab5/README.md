# Лабораторная работа 5

## Задание

Вариант 37. Создать игру «Крестики-нолики». Классическая игра с возможностью
игры против компьютера или другого игрока. Функциональность: заставка на всё
рабочее поле и экраны завершения игры. Нельзя использовать игровые библиотеки,
использование canvas приветствуется.

## Реализация

Приложение написано на React и собирается Vite. Разметка состоит из одного
корневого элемента `<main data-testid="app">`, в который монтируется приложение,
всё остальное создаётся компонентами.

Логика игры вынесена в модуль `src/game.js` и не зависит от React: там объявлены
выигрышные линии, функция `getResult` для поиска победителя или ничьей, функция
`getCurrentSign`, определяющая чья очередь, и функции поиска хода компьютера.
Лёгкий уровень выбирает случайную свободную клетку, непобедимый использует
алгоритм минимакс: он перебирает все продолжения партии и выбирает ход с лучшей
оценкой, причём глубина учитывается в оценке, поэтому компьютер выигрывает
быстрее и проигрывает дольше.

Интерфейс разделён на компоненты. `App` хранит состояние и правила переходов,
`ControlPanel` отвечает за выбор режима, сложности и знака, `GameBoard` рисует
поле, `ResultScreen` показывает экран завершения партии, `SplashScreen` —
заставку.

В состоянии хранится только то, что нельзя вычислить: поле, настройки и счёт.
Результат партии и очередь хода выводятся из поля при каждом рендере, поэтому
они не могут разойтись с полем. Обработчики обёрнуты в `useCallback`, чтобы не
пересоздаваться на каждый рендер. Пока ход принадлежит компьютеру, клетки
заблокированы, чтобы интерфейс не предлагал недоступное действие.

Поле нарисовано на canvas: сетка, знаки и линия победы рисуются в хуке
`useEffect` при каждом изменении поля. Поверх canvas лежит сетка из девяти
кнопок с прозрачным фоном: они принимают клики и дают доступность с клавиатуры.
Содержимое canvas недоступно программам чтения с экрана, поэтому каждая кнопка
содержит скрытую текстовую подпись своей клетки — это текстовая альтернатива
рисунку и одновременно обычное имя кнопки. Такое разделение позволяет рисовать
на canvas и при этом сохранить семантику кнопок.

Ход компьютера выполняется асинхронно: `useEffect` замечает, что очередь хода не
за игроком, и планирует ход через `setTimeout` с небольшой задержкой, а функция
очистки отменяет таймер, если состояние изменилось раньше.

Заставка показывается поверх всего рабочего поля при запуске и убирается либо по
кнопке «Начать игру», либо автоматически через полторы секунды, чтобы заставка
не могла заблокировать игру. Экран завершения появляется поверх поля, когда
партия закончилась, и сообщает результат.

Настройки и счёт сохраняются в local storage. Обращения к хранилищу обёрнуты в
`try`, потому что оно может быть недоступно, и при неудачной записи приложение
показывает, что настройки не сохраняются. Прочитанные значения не используются
напрямую: режим, сложность и знак сверяются со списком допустимых значений, а
счёт принимается только как целые неотрицательные числа, поэтому испорченная
запись в хранилище не ломает игру.

## Запуск

Установите зависимости и запустите сервер разработки:

```bash
npm install
npm run dev
```

Vite выведет адрес вида `http://localhost:5173`. Для сборки готового приложения
используйте `npm run build`.
