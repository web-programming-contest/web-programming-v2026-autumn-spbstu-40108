# Лабораторная работа 3

## Задание

Вариант 37. Реализуйте функцию `zipArrays(...arrays)`, которая объединяет
массивы поэлементно (например, `zipArrays([1, 2], ['a', 'b'])` →
`[[1, 'a'], [2, 'b']]`).

## Реализация

Функция `zipArrays` объявлена в `solution.js` и экспортируется именованным
export. Массивы принимаются через rest-параметр `...arrays`, поэтому их
количество не ограничено. Если не передан ни один массив, возвращается пустой
массив — это корректный результат объединения пустого набора. Дальше проверяются
входные данные: если какой-то аргумент не является массивом, выбрасывается
`TypeError`, а если длины массивов различаются, выбрасывается `Error`. После
проверок внешний цикл идет по индексам от нуля до общей длины, внутренний цикл
на каждом шаге берет из каждого массива элемент с текущим индексом и складывает
их в массив `group`. Готовая группа добавляется в результат методом `push`.
Входные массивы при этом не изменяются.

## Запуск

Решение является ES module. Импортируйте именованный export `zipArrays` из
`solution.js` и вызовите его, передав массивы через запятую:

```js
import {zipArrays} from './solution.js';

console.log(zipArrays([1, 2], ['a', 'b']));
// Вывод: [[1, 'a'], [2, 'b']]
```
