# Лабораторная работа 3

## Задание

Варинат 14. Реализуйте функцию countOccurrences(arr), которая возвращает объект
с количеством вхождений каждого элемента.

## Реализация

Перебор массива циклом for-of. Для каждого элемента счётчик в объекте
увеличивается на 1. В конце объект возвращается. Для пустого массива вернётся
пустой объект, исходный массив не меняется.

## Запуск

Импортируйте именованный export из `solution.js` как ES module.
