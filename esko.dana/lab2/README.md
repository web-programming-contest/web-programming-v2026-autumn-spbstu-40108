# Лабораторная работа 2

## Задание

Вариант 14. Написать функцию, которая преобразует цвет из HEX-формата в
RGB-формат (например, "#FF0000" -> "rgb(255, 0, 0)").

## Реализация

Функция hexToRgb в файле solution.js принимает строку вида "#FF0000" и
возвращает "rgb(255, 0, 0)". В HEX-цвете после решётки идут три пары символов:
красный, зелёный и синий. Функция вырезает каждую пару через slice, переводит её
в число через parseInt с основанием 16 и собирает результат шаблонной строкой.

## Запуск

Импортировать именнованный export из solution.js как ES module.
