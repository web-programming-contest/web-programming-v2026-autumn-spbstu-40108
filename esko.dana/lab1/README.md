# Лабораторная работа 1

## Задание

Вариант: 14. Создать горизонтальное навигационное меню, где активный элемент
выделяется другим цветом. Использовать теги `<nav>`, `<ul>`, `<li>`, `<a>`. Один
из пунктов меню должен быть активным (через `class="active"`).

## Реализация

Меню состоит из семантического блока `<nav>`, внутри него список `<ul>` с
пунктами `<li>`, в каждом пункте ссылка `<a>`.

Стили вынесены в отдельный файл `styles.css`:

- у `nav ul` задан `display: flex`, поэтому пункты стоят в одну строку; маркеры
  и отступы списка убраны (`list-style-type: none`, `margin: 0`, `padding: 0`);
- у ссылок `nav a` убрано подчёркивание, заданы цвет текста и `padding`, а
  `display: block` делает всю область пункта кликабельной;
- активный пункт отмечен классом `active` и стилем `nav a.active` (другой фон,
  цвет и жирное выделение);
- при наведении на пункт меняется фон (`nav a:hover`); правило для `.active`
  написано ниже `:hover`, поэтому активный пункт сохраняет свой вид и при
  наведении.

## Запуск

Откройте index.html в браузере.
