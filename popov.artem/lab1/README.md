# Лабораторная работа 1

## Задание

Вариант 37. Создать три div-элемента в виде прямоугольников: центральный зелёный
— с относительным позиционированием, левый красный — с абсолютным
позиционированием, под зелёным, правый синий — с абсолютным позиционированием,
над зелёным.

Крайние прямоугольники должны частично перекрывать центральный. Для размещения
использовать top, right, bottom, left, для порядка наложения — z-index.

## Реализация

Страница создана на HTML и CSS. Файлы проекта:

index.html — разметка страницы и три прямоугольника styles.css — размеры, цвета,
позиционирование и порядок наложения

Контейнер scene имеет position: relative. Красный и синий прямоугольники имеют
position: absolute и размещаются относительно контейнера. Зелёный прямоугольник
имеет position: relative.

Порядок наложения задан свойством z-index: красный — 1 зелёный — 2 синий — 3

## Запуск

Открыть файл index.html в браузере.
