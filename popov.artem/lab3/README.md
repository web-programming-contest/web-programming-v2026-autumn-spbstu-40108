# Лабораторная работа 3

## Задание

Вариант 37, задача 3.

Реализовать функцию `zipArrays(...arrays)`, которая объединяет несколько
массивов поэлементно.

## Реализация

Функция `zipArrays` реализована в файле `solution.js` и экспортируется с помощью
`export`.

Функция принимает произвольное количество массивов.

Алгоритм:

1. Проверяется наличие входных массивов.
2. Проверяется, что все аргументы являются массивами.
3. Проверяется одинаковая длина массивов.
4. Цикл `for` проходит по индексам элементов.
5. Метод `map` собирает элементы с одинаковыми индексами.
6. Возвращается новый двумерный массив.

Граничные случаи:

- Если аргументов нет, возвращается пустой массив.
- Если массивы пустые, возвращается пустой массив.
- Если длины массивов различаются, выбрасывается ошибка.
- Если аргумент не является массивом, выбрасывается TypeError.

Исходные массивы не изменяются.

## Запуск

Функция запускается через Node.js с использованием ES modules.

Из корня репозитория выполнить:

```powershell
node --input-type=module -e "import { zipArrays } from './popov.artem/lab3/solution.js'; console.log(zipArrays([1, 2], ['a', 'b']));"
```
