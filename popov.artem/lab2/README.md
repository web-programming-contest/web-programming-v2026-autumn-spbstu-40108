# Лабораторная работа 2

## Задание

Вариант 37.

Реализовать функцию `formatPhoneNumber(phoneStr)`, которая форматирует строку из
10 цифр по шаблону `+7 (XXX) XXX-XX-XX`.

Пример: `9123456789` → `+7 (912) 345-67-89`.

## Реализация

Функция находится в файле `solution.js` и экспортируется по имени
`formatPhoneNumber`.

Перед форматированием функция проверяет, что аргумент является строкой из 10
цифр. При неправильном типе, длине или символах функция сообщает об ошибке.

Метод `slice` делит исходную строку на четыре части: 3, 3, 2 и 2 символа. Затем
части собираются в одну строку с помощью шаблонной строки. Результат
возвращается через `return`.

## Запуск

Из корня репозитория запустить интерактивный режим Node.js:

```bash
node
```

Импортировать функцию и вызвать её:

```js
const {formatPhoneNumber} = await import('./popov.artem/lab2/solution.js');
formatPhoneNumber('9123456789');
```

Ожидаемый результат: `+7 (912) 345-67-89`.

Для выхода из Node.js ввести `.exit`.
