# Лабораторная работа 4

## Задание

Вариант 20. Разработать веб-приложение для управления каналами и их
подписчиками. У каждого канала есть числовой идентификатор, название и массив
имён подписчиков. Модель должна поддерживать добавление и удаление подписчиков и
предоставлять их текущее количество через геттер `subscriberCount`.

Для массива каналов реализовать пять операций:

- сгруппировать каналы по количеству подписчиков;
- получить список уникальных имён подписчиков;
- найти все каналы, на которые подписан указанный подписчик;
- для каждого подписчика получить список его каналов;
- найти все каналы с максимальным количеством подписчиков.

На странице показать карточки с названием канала, списком подписчиков и их
количеством. Предусмотреть формы создания канала и добавления подписчика, а
также кнопки удаления канала и подписчика. Добавление и удаление должны
выполняться асинхронно через `Promise` и `setTimeout`. После изменения карточки
и результаты операций с массивом должны обновляться без перезагрузки страницы.
Сохранять каналы и подписчиков в `localStorage` и восстанавливать их при
следующем открытии страницы.

## Реализация

`model.js` экспортирует класс `Channel` с полями `id`, `name`, `subscribers`,
методами `addSubscriber(name)`, `removeSubscriber(name)` и геттером
`subscriberCount`.

Функции для массива каналов:

- `groupChannelsBySubscriberCount(channels)` возвращает `Map`, в котором каждому
  количеству подписчиков соответствует массив каналов.
- `getUniqueSubscribers(channels)` — массив уникальных имён подписчиков.
- `findChannelsBySubscriber(channels, name)` возвращает каналы с указанным
  подписчиком.
- `groupSubscribersByChannel(channels)` возвращает `Map`, в котором каждому
  имени подписчика соответствует массив его каналов.
- `findLargestChannels(channels)` возвращает все каналы с максимальным
  количеством подписчиков.

Результаты всех пяти операций пункта 4.2 выводятся под карточками каналов. Для
поиска каналов введите имя подписчика и нажмите «Найти каналы». Результаты
автоматически обновляются при изменении каналов и подписчиков.

В `main.js` операции выполняются через `Promise` и `setTimeout` с задержкой 300
мс. После изменения данные сохраняются в `localStorage` под ключом
`variant20-channels`, а карточки обновляются. При загрузке восстанавливаются
экземпляры класса. ID — уникальное целое положительное число. Пустые имена и
повторные подписчики в одном канале не допускаются.
