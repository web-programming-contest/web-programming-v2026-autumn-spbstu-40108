# Лабораторная работа 1

## Задание

Вариант 20 Создать диалоговое окно, имитирующее окно подтверждения действия
(например, "Вы уверены?"). Окно должно содержать:

- Заголовок (например, "Подтверждение");
- Текст сообщения (например, "Вы действительно хотите удалить этот файл?");
- Кнопки "OK" и "Отмена". Окно должно быть центрировано на странице.

## Реализация

Страница состоит из основного контейнера, внутри которого расположено диалоговое
окно. Диалоговое окно разделено на три части: заголовок, область сообщения и
нижнюю часть с кнопками «ОК» и «Отмена». Для центрирования диалогового окна на
странице используется свойство display: flex. Для оформления окна используются
фоновые цвета, границы и скругление углов. Для кнопок задан фиксированный
размер, а свойство gap используется для создания расстояния между ними. При
наведении курсора на кнопки изменяется цвет их фона.

## Запуск

Откройте `index.html` в браузере.
