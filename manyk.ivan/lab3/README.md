# Лабораторная работа 3

## Задание

Вариант 20. Реализовать функцию slidingWindowSums(arr, k), которая возвращает
массив сумм все окон длиной k.

## Реализация

Сначала функция вычисляет сумму первого окна длиной k. Затем последовательно
сдвигает окно на одну позицию. При каждом сдвиге из текущей суммы вычитается
первый элемент предыдущего окна и прибавляется новый элемент, попавший в окно.

## Запуск

Импортируется именованная функция из solution.js.
