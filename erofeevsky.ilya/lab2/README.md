# Лабораторная работа 2

## Задание

Вариант 13

Сделайте функцию, которая параметром будет получать дату, а возвращать знак зодиака, соответствующий этой дате.

## Реализация

Используется экспортируемая функция *getZodiacSign*, которая принимает день и месяц, а после возвращает название знака с заглавной буквы.

**Алгоритм**

Сначала происходит проверка валидности даты, то есть чтобы выполнялись следущие условия:

* Целочисленное значение дня и месяца
* Численное написание дня и месяца

В случае не соответсвия с одним из этих пунктов программа должна вывести: "Некорректная дата"

После проверки валидности, дальше идёт проверка даты на соответсвие с датами знаков зодиака.

**Граничные случаи**

Функция проверяет не только тип данные, но и календарное соответствие, например:
* getZodiacSign(30, 2) -> Некорректная дата (в феврале максимально 29 дней)
* getZodiacSign(31, 4) -> Некорректная дата (в апреле 30 дней)
* getZodiacSign(0, 1) -> Некорректная дата (Нумерация дней в месяце начинается с 1)
* getZodiacSign(12, 13) -> Некорректная дата (В году 12 месяцев)

Так же не принимаются отрицательные значения.
* getZodiacSign(-1, 12) -> Некорректная дата

Знаки зодиака пересекают календарные месяцы, поэтому необходимо корректно обработать последний день одного знака и первый день следующего, например:
* getZodiacSign(19, 1) -> Козерог
* getZodiacSign(20, 1) -> Водолей


## Запуск

Импортируйте именованный export из `solution.js` как ES module.

```javascript
import { getZodiacSign } from './solution.js';

console.log(getZodiacSign(25, 8)); // Ожидаем: "Дева"
console.log(getZodiacSign(25, 5)); // Ожидаем: "Близнецы"
console.log(getZodiacSign(30, 2)); // Ошибка: "Некорректная дата"
console.log(getZodiacSign(99, 1)); // Ошибка: "Некорректная дата"
console.log(getZodiacSign(24, 13)); // Ошибка: "Некорректная дата"
console.log(getZodiacSign(0, 1)); // Ошибка: "Некорректная дата"
console.log(getZodiacSign(-1, 12)); // Ошибка: "Некорректная дата"
console.log(getZodiacSign("abc", 1)); // Ошибка: "Некорректная дата"
// Граничная даты: "Козерог" или "Водолей"?
console.log(getZodiacSign(19, 1));
console.log(getZodiacSign(20, 1));
```
