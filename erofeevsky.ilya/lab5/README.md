# Лабораторная работа 5

## Задание

**Вариант 13**

Создайте простое чат-приложение с сохранением истории сообщений в браузере
(localStorage). Приложение должно позволять вводить имя пользователя, отправлять
сообщения, просматривать историю сообщений даже после перезагрузки страницы.
Функциональность:

- сохранение всех сообщений в localStorage;
- автоматическая загрузка истории при открытии чата;
- отображение имени пользователя рядом с сообщением;
- дата/время каждого сообщения;
- очистка истории (кнопка "Очистить чат").

## Реализация

### 1. Архитектура React-компонентов

Интерфейс разделен на модульные компоненты:

- **`App` (`src/main.jsx`)** — корневой контейнер-распорядитель. Управляет
  глобальным состоянием чата, отвечает за синхронизацию с `localStorage`,
  содержит шапку с настройкой никнейма и кнопку очистки истории.
- **`MessageList` (`src/components/MessageList.jsx`)** — компонент истории
  переписки (`data-testid="chat-history"`). Отрисовывает информационную заглушку
  при отсутствии сообщений либо массив карточек сообщений
  (`data-testid="chat-item"`).
- **`ChatMessage`** (вспомогательный внутри `MessageList`) — карточка отдельного
  сообщения, отображающая автора, текст и время.
- **`MessageInput` (`src/components/MessageInput.jsx`)** — форма ввода нового
  сообщения. Содержит поле ввода (`data-testid="chat-message"`) и кнопку
  отправки (`data-testid="chat-send"`).

### 2. Состояние приложения (State Management)

- **`username`** (`string`) — текущее имя пользователя. Инициализируется из
  `localStorage` (`chat_name`), сохраняется при каждом вводе через `useEffect`.
- **`messages`** (`Array<Object>`) — массив сообщений вида:
  ```javascript
  {
    id: 1730894400000,
    author: "Пользователь",
    text: "Текст сообщения",
    time: "15:20:00"
  }
  ```

## Запуск

Выполните `npm install`, затем `npm run dev` в каталоге лабораторной.
