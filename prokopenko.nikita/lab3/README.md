# Лабораторная работа 3

## Задание

Вариант 19. Реализовать функцию `sortArrayByParity(arr)`. Она возвращает новый
массив: сначала все чётные числа, потом все нечётные. Порядок внутри этих двух
групп может быть любым. Пустой массив даёт пустой результат.

## Реализация

Функция один раз проходит по массиву. Число считается чётным, если остаток от
деления на 2 равен 0, и попадает в массив `even`. Остальные числа попадают в
массив `odd`. Ответ — эти два массива, склеенные друг за другом. Исходный массив
остаётся прежним.

## Запуск

Импортируйте именованный export из `solution.js` как ES module:

```js
import {sortArrayByParity} from './solution.js';

console.log(sortArrayByParity([3, 1, 2, 4]));
```
