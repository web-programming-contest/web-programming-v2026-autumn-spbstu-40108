# Лабораторная работа 1

## Задание

Создать страницу с формой регистрации по варианту 23
(full-registration-form-gray):

- Форма с серым фоном #f2f2f2 (rgb(242, 242, 242)) и цветом текста #333 (rgb(51,
  51, 51)).
- Отступы между полями 10px.
- Поля ввода: имя, фамилия, email, пароль, подтверждение пароля, дата рождения,
  радиокнопки выбора пола и кнопка отправки.

## Реализация

Разметка выполнена с использованием валидного HTML5 и семантических элементов
без инлайн-стилей. В файле `styles.css` заданы стили оформления: выравнивание
формы по центру, адаптивный flex-контейнер, отступы gap: 10px между полями, цвет
фона #f2f2f2 и цвет текста #333. Применены классы в формате kebab-case,
отсутствуют селекторы по ID и директива !important.

## Запуск

Открыть файл `index.html` в браузере.
