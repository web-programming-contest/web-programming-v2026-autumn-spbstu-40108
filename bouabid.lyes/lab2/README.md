# Лабораторная работа 2

## Задание

Реализовать функцию генерации случайного HEX-цвета по варианту 23
(generate-hex-color). Функция должна возвращать строку формата `#RRGGBB` из
шести шестнадцатеричных символов.

## Реализация

Функция `generateHexColor` экспортируется именованно согласно спецификации
ES-модулей. Для формирования цвета используется случайная выборка символов из
шестнадцатеричного алфавита `0123456789ABCDEF` с возвращением строки в верхнем
регистре, предваряемой символом `#`.

## Запуск

Импортировать функцию в ES-модуле:

```js
import {generateHexColor} from './solution.js';
console.log(generateHexColor());
```
